## About The Project

![image](https://github.com/user-attachments/assets/39655961-0d2b-47d2-b66a-be1ba67e6ccf)

An exam system web application designed to facilitate studying for both students and teachers.
It provides secure authentication via Google and email registration. Users can register either as a student or a teacher. Teachers can add new questions and create exams, while students can access and take exams to test their knowledge and skills.


### Key Features:

- Registeration wih Email/Google account
- Take exams from various subjects (Student role only)
- View your previous results (Student role only)
- Add new questions to exams (Teacher role only)

2. **Open the project**
